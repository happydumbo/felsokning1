# IK118G – Övningar

Övningar i C#/WPF att träna på. Varje mapp är ett eget övningsset med ett eget projekt.

## Så här gör du

1. Klicka på **Use this template** här på GitHub för att skapa din egen kopia (eller klona repot).
2. Öppna mappen för det set du ska jobba med i **Visual Studio** (Öppna mapp / Open Folder).
3. Läs `README.md` inne i mappen – där står vad du ska göra.
4. Tryck **F5** för att köra.

## Övningsset

| Mapp | Innehåll |
|------|----------|
| `01-Felsokning` | Finn felen + nästlade loopar |
| `02-Chateau` | Loopa en array + söka i text (räkna Château- och Amarone-viner) |
